# 富春夜渡

走进一幅原创青绿山水画。乘一叶舟，听雨，放一盏河灯。

## 体验

- 点击「乘舟入画」，WASD / 方向键前后左右行舟，拖动画面可连续 360° 环顾，滚轮亦可沿视线前后移动。
- 「俯瞰山水」或 V 切换俯瞰视角，拖动环绕、滚轮缩放；手机支持双指缩放。
- 手机上用方向按钮移动、手指拖动环顾。
- 「自动漫游」带你经过松风渡口、隔岸人家、月下江心，抵达终点自动停下。
- 空格或「放一盏河灯」留下会随水漂流的河灯；「晴夜 / 烟雨」切换天气。
- 声音默认关闭，点击开启浏览器合成的江流底噪和放灯音色。
- 「看原画」查看素材及近、中、远层次；「回渡口」重置位置，保留河灯。

## 素材与实现

画作与两张补充分层素材均由内置 imagegen 生成，主题为原创青绿山水《富春夜渡》，不是黄公望《富春山居图》的扫描或复原。

当前为真实三维版：用 Three.js 建立有体积的山峰、河岸、松树、村落、拱桥和小舟。近景与中景不再依靠透明画片，场景固定于世界坐标，可连续 360° 环顾。新增「俯瞰山水」可绕船旋转、缩放；江面使用实时平面反射，倒影跟随山体与镜头变化。原画保留为创作与构图对照。当前材质版使用 Poly Haven 的 CC0 扫描岩壁、树木模型以及岩石、地表、木板、屋顶 PBR 贴图，模型来源见 `dist/assets/ASSET-CREDITS.md`。增加草丛风动、实时阴影、水面法线与实时倒影。

航行仍限制在画境江面内，岸边有碰撞边界，俯瞰镜头会避开山体。这是参照原画构图和配色的风格化三维再创作，不是从原图自动还原真实地形。早期 2.5D 版本可在 Git 历史中查看。

所有运行资源（除可选 Google 字体外）保存在仓库。无后端、无 API 调用、无 API key，无客户数据。字体不可用时退回系统宋体。Three.js 0.180.0 使用 MIT 许可证，见 `dist/assets/THREE-LICENSE.txt`。

## 本地运行与发布

```sh
python3 -m http.server 4173 --directory dist
```

访问 http://localhost:4173 。不需要安装依赖或构建。GitHub Actions 将 `dist/` 发布到 GitHub Pages。
