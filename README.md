# 富春夜渡

走进一幅原创青绿山水画。乘一叶舟，听雨，放一盏河灯。

## 体验

- 点击「乘舟入画」，WASD / 方向键前后左右行舟，拖动画面环顾，滚轮亦可前后移动。
- 手机上用方向按钮移动、手指拖动环顾。
- 「自动漫游」带你经过松风渡口、隔岸人家、月下江心，抵达终点自动停下。
- 空格或「放一盏河灯」留下会随水漂流的河灯；「晴夜 / 烟雨」切换天气。
- 声音默认关闭，点击开启浏览器合成的江流底噪和放灯音色。
- 「看原画」查看素材及近、中、远层次；「回渡口」重置位置，保留河灯。

## 素材与实现

画作与两张补充分层素材均由内置 imagegen 生成，主题为原创青绿山水《富春夜渡》，不是黄公望《富春山居图》的扫描或复原。

采用 Three.js：远景画幕、中景透明山岸、近景透明松树置于不同三维深度，配合着色器江面、空间河灯、小舟与萤火形成可行舟的 2.5D 画境。可在有限江面内自由移动与环顾，不声称是完整 360° 的单图三维重建。河面倒影为原画采样与程序波纹构成的风格化效果。

所有运行资源（除可选 Google 字体外）保存在仓库。无后端、无 API 调用、无 API key，无客户数据。字体不可用时退回系统宋体。Three.js 0.180.0 使用 MIT 许可证，见 `dist/assets/THREE-LICENSE.txt`。

## 本地运行与发布

```sh
python3 -m http.server 4173 --directory dist
```

访问 http://localhost:4173 。不需要安装依赖或构建。GitHub Actions 将 `dist/` 发布到 GitHub Pages。
