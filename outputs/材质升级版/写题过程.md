作品：富春夜渡
链接：https://toller892.github.io/fuchun-night-voyage/

1. 用 AI 原创青绿山水画作为构图起点，先做分层行舟，再搭建三维山岸、村落与石桥。
2. 根据反馈重做材质与植被：从 Poly Haven 获取 CC0 扫描岩壁、树木，以及岩石、地表、木板和瓦片纹理。
3. 使用颜色、法线、粗糙度贴图，让表面表现出裂隙、树皮、木纹和瓦片起伏；地形根据坡度混合岩石与地表材质。
4. 将高面数树模型简化为桌面和手机版本，使用实例化重复放置树木与岩岸，加入随风摆动的草丛。
5. 调整山体轮廓，加入方向光阴影、雾、带法线波纹的水面与实时倒影。
6. 保留 360° 环顾、行舟、俯瞰环绕、放灯、烟雨和环境声，检查电脑与手机浏览器，再更新网页与源码。

这是基于原画的风格化三维场景再创作，不是对古画或真实地形的精确还原，也不宣称达到 3A 游戏制作质量。没有使用 Nintendo 的游戏素材。运行无需 API key，不包含客户数据。
