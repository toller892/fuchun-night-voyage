作品名：富春夜渡

我把题目交给 Codex，要求按 30 分钟「走进一幅画」的目标完成网页、公开源码、截图和写题过程。素材由 AI 自选，没有使用真实客户名或客户数据。

1. 确定创意：不在画外看山水，而是成为画里的行舟人。选择原创青绿山水，以「松风渡口 → 隔岸人家 → 月下江心」串起体验。
2. 生成素材：使用内置 imagegen 生成主画及同风格的山岸、松树透明画片。主画明确包含近景松树芦苇、中景村落石桥、远景群山月色。页面内可随时打开原画对照。
3. 把平面变成空间：用 Three.js 将远景、中景、近景放到不同深度，加入有波纹和风格化倒影的三维江面。移动时，近处松树与两岸村落产生不同速度的视差。
4. 让人能进去：实现 WASD / 方向键自由行舟、拖动环顾、自动漫游、手机方向按钮，以及回到渡口。探索范围为有限江面；这是可行舟的 2.5D 画境，不是完整 360° 三维重建。
5. 让世界回应：访客能放河灯，灯出现在江面中的实际位置并漂流；可切换晴夜与烟雨，开启浏览器合成环境声。放灯也有轻柔音色反馈，默认不自动播放声音。
6. 整理交付：实际运行浏览器检查进入、移动、放灯、天气、声音开关、回渡口及手机布局，截取真实界面，发布静态网站并保留公开源码。

建议按顺序上传前四张截图：
- 01-初入画境.png：入口与整体画面。
- 02-行舟深入.png：移动和改变视角后的纵深。
- 03-一灯一愿.png：放灯后成为画中人的瞬间。
- 04-原画与层次.png：主画素材和近、中、远层次说明。

05-手机画境.png 可作为第五张补充。AI 评分只看前四张。

技术：静态 HTML / CSS / JavaScript、Three.js 0.180.0、WebGL 着色器、Web Audio。无需 API key，运行时不调用生成式 AI API。
