作品名：富春夜渡 · 三维画境

作品链接：https://fuchun-night-voyage.plucky-lemur-5446.chatgpt.site
备用链接：https://toller892.github.io/fuchun-night-voyage/

我让 AI 以原创青绿山水为素材，先做出分层行舟体验，再将它升级成真正有体积的 3D 世界。

1. 用 AI 生成原画，明确近景松树芦苇、中景村落石桥、远景群山月色。
2. 以原画构图和配色为灵感，用 Three.js 建立山峰、河岸、松树、村落、拱桥和小舟的三维模型，山体表面融入原画笔触纹理。
3. 实现连续 360° 环顾、自由行舟和俯瞰环绕，山体与房屋可以从不同方向观察，并加入岸边碰撞和镜头避障。
4. 江面改为实时反射，山、树、屋顶和河灯的倒影随视角改变。保留放灯、烟雨、环境声、自动漫游与手机触控。
5. 在浏览器中检查移动、转身、俯瞰、碰撞和主要按钮，截图后更新公开 GitHub 仓库与网站。

这是一份参照原画的风格化三维再创作，不是对原图真实地形的自动还原。运行无需 API key，不含客户数据。

截图请按 01、02、03、04 的顺序提交，05 为手机补充；原画可在网页右上角「看原画」中查看。
